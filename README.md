# 📸 Photo Gallery

A photo gallery web application built with **React** and **Firebase**.

This project allows users to authenticate, upload images, and store image information using Firebase services.

## ✨ Features

- 🔐 User Authentication with Firebase Authentication
- 📸 Upload images using Firebase Storage
- ☁️ Store image URLs in Firestore
- 🖼️ Display uploaded images
- 📊 Upload progress tracking
- ⚡ Real-time interaction with Firebase
- 📱 Responsive user interface

## 🛠️ Technologies

- **React**
- **JavaScript**
- **Firebase Authentication**
- **Firebase Firestore**
- **Firebase Storage**
- **CSS**
- **Vite**

## 🔥 Firebase Services

This project uses Firebase for its backend services.

### Authentication

Firebase Authentication is used for user registration and login.

### Firestore

Firestore is used to store application data and image URLs.
